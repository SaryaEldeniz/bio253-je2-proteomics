# Bio253 JE2 proteome and phosphoproteome project

Sarya and George's Project I asks: **Which functional modules respond to PASN, and where do Stk1/Stp1 and their candidate targets sit?**

Open [Sarya_George/Sarya_George.Rproj](Sarya_George/Sarya_George.Rproj) in RStudio. The group workflow is now organized by project step, with each step's code, figures, tables and progress notes together.

**Start with the [repository guide](REPOSITORY_GUIDE.md)** for the folder map, required data and instructions for finding particular results.

| Location | Purpose |
| --- | --- |
| [Sarya_George/](Sarya_George/README.md) | Group analysis and figures, organized into Steps 1–10. |
| [course_starter/](course_starter/README.md) | Original course helpers, Quarto teaching notebooks and course project. |
| [Sarya_George/00_shared/](Sarya_George/00_shared/README.md) | Setup, code/provenance indexes and repository history. |
| [Sarya_George/90_archive/](Sarya_George/90_archive/README.md) | Earlier exploratory code retained for reference. |

The latest labelled phosphosite interaction figures are in [Step 7](Sarya_George/steps/07_phosphosite_results/README.md). The four matching supplementary mutant-versus-ancestor volcanoes are in [Step 8](Sarya_George/steps/08_mutant_venn/README.md). The sequence logos and protein/structure figures are in [Step 9](Sarya_George/steps/09_sequence_logos/README.md).
