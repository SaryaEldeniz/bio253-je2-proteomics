# Local course data

Use the current JE2 course data from the lecturer. Original measurements are not
included in this repository. Preserve the lecturer's `derived/` folder.

Set `JE2_DATA_DIR` to the directory containing `derived/`, or copy
`config/data_dir.example.txt` to `config/data_dir.txt` and replace its first line
with your local data directory. The local setting is ignored by Git.

The analysis reads this directory and writes results only inside the code project.
It does not change the source data. `reports/step01_inputs.md`, generated by Step 1,
records the input names, sizes and MD5 hashes needed to compare dataset versions.

Do not commit original course tables, sequences, workbooks or instrument files.
