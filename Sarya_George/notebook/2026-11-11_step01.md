## Question

Can we verify the JE2 sample labels and define sign-explicit comparisons before
developing the Project I figures?

## Key results

- 27 sample labels in each layer; 3 genotypes x 3 media x 3 replicate labels.
- Nine shortened Excel pulse labels recover the expected canonical identifiers.
- Reinjected phospho labels: JE2stk_pulseSN_1 and JE2stk_pulseSN_2. These are not
  additional experimental replicates; no total-proteome reinjections are flagged.
- 33 available contrasts in each layer; 12 comparisons selected for the project
  plan (9 core, 1 follow-up and 2 optional).
- Total abundance/DEA feature counts before contaminant filtering: 2348/2324.
  Phospho STYH counts: 4278/4235. Omitted feature identities were saved locally.
- 28/28 design checks and 10/10 focused code checks passed. The focused checks
  also passed with a data path that has no unpublished derived tables.

## Problems, interpretation and limits

The original starter helper-test suite could not start because testthat is not
installed. This is recorded separately from the passing checks; no passing result
is claimed for that suite. The available R installation emitted locale and
package-build warnings. The analysis script and focused checks completed normally.

Sample-label agreement does not prove good measurement quality. Matching replicate
numbers across media do not prove a paired design. The course notes a possible
stp/Stk1 confound, to be examined using actual protein measurements in Step 2.

An independent code review recommended deferring private-data checks until a
reading function is called, so synthetic checks can work in a clean GitHub clone.
It also recommended checking nonmissing contrast names and nonzero coefficient
counts; these changes were made before the final run.
