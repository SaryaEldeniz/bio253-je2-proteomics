# 2026-11-11: Step 3, annotation and public-resource access

## Question and scope

How can JE2 identifiers be mapped reproducibly for functional annotation and
interaction queries? The user reports the data are already validated and asked
to skip Step 2. No sample QC or mutant-validation analysis was repeated.

## Work performed

Read the supplied metadata/terms zip and local STRING aliases/physical links.
Built an auditable master map and searchable aliases using exact protein keys.
Added quality flags, coverage denominators, local interaction lookup and familiar
JE2 labels for reference-organism edges. Added R clients for UniProt, STRING and
KEGG, with cached public responses, provenance, request limits and visible errors.

## Key results

- Master map: 4,189 source entries and 55,076 alias records. Five mapping checks passed.
- Total DEA: 2,229 ordinary CDS entries; 2,107 good mappings to 2,080 UniProt IDs.
- Phospho DEA: 1,109 ordinary parent entries; 1,068 good mappings to 1,063 IDs.
- All total CDS entries resolve through supplied STRING aliases; annotation-term
  and network-edge coverage are lower and reported separately.
- The metadata reclassifies 68 total-DEA entries as contaminants despite the DEA
  flag being FALSE. There are also 24 flagged/unmatched contaminants and three
  pseudo/frame translations. All remain visible in the audit.
- 12/12 synthetic identifier checks and 17/17 offline API checks passed.
- Live: five UniProt primary accessions and five STRING cross-reference matches
  in reference taxon 93061; four selected edges in each requested network type,
  eight partner rows, 194 annotation rows, four KEGG pathway links and one gene record.

## Decisions and limits

Use good UniProt orthologs for online annotation, preserve exact JE2 coordinates
for site work, and retain many-to-one target collisions. Do not treat a local
STRING alias as proof that a protein has terms or edges. Public-context partners
are not automatically measured, changed or direct kinase substrates.

The first httr2 probe could not read package-version metadata in this environment;
the clients use curl/jsonlite/digest instead without changing installed libraries.
An initial curl probe was blocked by host network restrictions. After network
permission was granted, all selected live tests succeeded. The original helper
test suite was attempted but still could not start because testthat is missing.

## AI use

Codex implemented and ran the code. One agent implemented/reviewed public-resource
clients against official documentation; another independently reviewed mapping
joins, biological interpretation and alias handling. Descriptive protein names
were added to the searchable vocabulary after review feedback.
