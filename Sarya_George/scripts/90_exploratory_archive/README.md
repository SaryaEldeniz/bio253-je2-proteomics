# Historical exploratory code

These scripts preserve earlier investigations and checks for provenance. They are not the official final pipeline.
They include B/G topic previews, an exploratory pathway analysis and mapping/source inspections.
Run archived scripts only from the Sarya_George folder; a guard prevents outputs being written outside its ignored results directory.
Exploratory pathway plots have historical hard-coded captions and selected examples: do not present them as final enrichment results.
Run I_pathway_preview.R before I_pathway_plot.R if revisiting that preview. Optional historical workbook inspections require the Week 2 source folder.
Paths use the project configuration; JE2_WEEK2_DIR can override the inferred Week 2 folder. Intermediate files remain under ignored results/exploratory/.
