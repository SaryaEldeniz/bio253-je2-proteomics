# Poster network figures

The 75-protein figure now uses darker poster-visible edges (#42566A): confidence maps monotonically to linewidth 0.25-0.60 mm and opacity 0.55-0.85. Nodes, halos, labels, outlines and all 412 associations are retained. Reproduce with `source("steps/06_string_network/scripts/06_render_visible_poster_edges.R", encoding="UTF-8")`. The earlier SVG/PNG/PDF is preserved in `90_archive/figures/step06_before_visible_edges/`; [validation checks](../../reports/poster_networks/visible_edge_style_checks.txt) confirm retained input/layout geometry.

Exact 49-, 67- and 75-protein input sets can be shown separately; these are not the former 61-node one-round expansion. The 75-protein set restores all eight previously held proteins to the original 67-protein list. All supplied nodes and edges are retained, including isolates. Stk1/Stp1 are pinned symmetrically at the centre for biological prominence, not inferred hub status.

Pathway outlines use blue, orange, charcoal and purple, plus distinct line types, labels and P/R/N/T node badges. Node centres are neutral white, with dark anchors. The default uses freshly retrieved STRING KEGG annotation groups, not Leiden clustering. Additional selected proteins outside those four maps appear in a grey enclosure with C badges; this is not a claim that they lack other functions or pathways. Historical course review flags remain in the source metadata and are not automatically applied to fresh KEGG membership. Actual multiple memberships, if present, have multiple badges and participate in overlapping outlines without duplicate nodes.

Ring order is inner stk/anc, middle stp/anc, outer stp/stk. Signed original protein interaction effects use a shared <U+00B1>2 colour scale; grey means unavailable/unsuitable quantitative estimate and white means zero. Black dots mark protein FDR<0.1. Position does not show biological distance, edges are functional associations, and neither establishes direct phosphorylation.

PNG is 300 dpi; PDF and SVG preserve vectors. Canvas aspect follows occupied coordinates and a compact single-row footer. Poster coordinates, outline geometry and minimum-distance checks are exported beside source tables. Set JE2_POSTER_SETS=75 to render only the new 75-protein figure; existing figures and geometry rows for other lists are preserved. Without this variable, the script renders each available 49-, 67- and 75-protein input. To reproduce optional original-course grouping, set JE2_POSTER_ANNOTATIONS=course before running; those files receive a _course_scope suffix and do not replace live-group figures.
