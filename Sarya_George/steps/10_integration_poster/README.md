# Step 10 · Integrated report, abstract and poster material

This folder assembles the existing interpretation and presentation material. Read the dated notes and source reports when selecting the current result version; older integrated reports retain their original findings and context.

| Subfolder | What to find |
| --- | --- |
| [reports/](reports/) | Integrated report as Quarto/HTML and its evidence table. |
| [reports/abstract/](reports/abstract/) | Abstract text/draft, title, recipe/evidence checks, primary-literature bibliography, RIS files, search log and word count. |
| [scripts/](scripts/) | Slide-evidence preparation; `abstract/` holds bibliography/abstract preparation; `methods_illustrations/` holds SVG/slide generators and render/export helpers. |
| [figures/methods_svg/](figures/methods_svg/README.md) | Editable blue-green methods panels, combined SVG, PNG previews and SVG ZIP. |
| [figures/slide_summary/](figures/slide_summary/README.md) | Three total-proteome volcano images prepared for the summary slide. |
| [presentations/](presentations/) | Existing PowerPoint summary slide and PNG preview. |
| [notebook/](notebook/) | Integrated-report, abstract, methods-illustration and presentation notes. |

These materials use previously generated analysis outputs. The abstract-preparation script can query public bibliographic metadata; full caches remain local. Methods/slide scripts may require their documented local graphics or presentation tooling.

The current main phosphosite volcanoes remain in [Step 7](../07_phosphosite_results/figures/volcanoes/), supplementary comparisons in [Step 8](../08_mutant_venn/figures/volcanoes/), and network illustrations in [Step 6](../06_string_network/figures/poster_networks/). This avoids storing competing copies of the same analysis figure in the poster folder.
